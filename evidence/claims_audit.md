# Claims audit — load-bearing numbers in `report/report.tex`

*Built 2026-06-10; extended 2026-06-12 (v1.9, LTT 2025 wave). Every claim the report's argument rests on, classified by provenance:*
- **CITATION** = a published number we merely cite (verify against the cited source).
- **PULLED** = retrieved from a federal API or published statistical table (verify against NAEP Data Explorer / Digest).
- **COMPUTED** = produced by this repo's analysis code (verify by re-running the script or `python3 checks.py`).

*Each row's verification path is executable by a human in under 5 minutes. "NDE" = NAEP Data Explorer at
https://www.nationsreportcard.gov/ndecore/landing (Main NDE; choose subject/grade, jurisdiction National, cross-tab year).
Automated freeze/recompute tests for the COMPUTED rows live in `checks.py` (repo root).*

## Known provenance gaps (flagged, not fixed here)

1. **LTT percentiles and reading-for-fun shares are not in `data/ltt.csv`** (which holds means only). The headline P10 −12.6 (claim A5) and the Figure 9/14 series live as hard-coded literals in `analyze_ltt.py`, documented with sources in `evidence/ltt_evidence.md`. They verify cleanly against Digest 222.85 / LTT highlights, but they are PULLED-by-hand, not recomputable from repo raw data. `checks.py` T1.11 at least pins the script literal to the evidence file.
2. **`data/phonebans.csv`, `data/waivers.csv`, `data/commoncore.csv` carry no per-row source URLs** — coding provenance is "agent-verified June 2026" (STATE.md) with general sources in footnotes 3–4 of the report (ED per-state pages, CRS R42328, EdWeek; NCES State Education Reforms Table 2.17). The spot-check protocol in `docs/verification_checklists.md` covers this.
